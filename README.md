# Machine Learning Forecasting and Optimization of Crop Production and Food Prices in Ghana

## Overview

This project aims to develop machine learning models to forecast crop production and staple food prices in Ghana. The forecasts will then be incorporated into an operations research optimization model to support agricultural planning and decision-making.

## Objectives

- Forecast crop production for selected staple crops in Ghana.
- Forecast staple food prices using historical and socioeconomic data.
- Compare statistical and machine learning forecasting models.
- Develop an optimization model for agricultural planning and/or food distribution.
- Provide data-driven recommendations for policymakers.
